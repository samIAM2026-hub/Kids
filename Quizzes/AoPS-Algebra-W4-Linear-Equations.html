⚖️ Linear Equations

An equation is a balance. Whatever you do to one side, do to the other, and it stays true. This week is about using that one idea well: tidy each side, clear the fractions, turn a story into one equation, and check that your answer is actually allowed.

1 · Do the same thing to both sides

Solving a linear equation is always the same three moves:

  1. Tidy each side. Multiply out brackets and collect like terms, so each side is just “some x’s plus a number”.
  2. Gather. Add or subtract so all the x’s end up on one side and all the plain numbers on the other.
  3. Divide by the number in front of x.

Why is this allowed? Because the two sides are equal. If you add 4x to two equal things, they are still equal. You can do anything you like — as long as you do it to both sides.

Example
Solve 5x + 3 − 2x = 11 − 4x + 6.
  1. Tidy each side: left is 3x + 3, right is 17 − 4x.
  2. Add 4x to both sides: 7x + 3 = 17.
  3. Subtract 3 from both sides: 7x = 14. Divide by 7: x = 2.
  4. Check in the original: left 10 + 3 − 4 = 9, right 11 − 8 + 6 = 9 ✓
Answer: x = 2
Example · brackets with a minus in front
Solve 3(x − 4) − (2x − 5) = 7 − 2(x + 1).
  1. Left: 3x − 12 − 2x + 5 = x − 7. The minus in front of the bracket flips both signs inside: −(2x − 5) = −2x + 5.
  2. Right: 7 − 2x − 2 = 5 − 2x.
  3. Now x − 7 = 5 − 2x. Add 2x and add 7: 3x = 12, so x = 4.
  4. Check: left 3(0) − 3 = −3, right 7 − 10 = −3 ✓
Answer: x = 4
⚠️ Trap

−(2x − 5) is −2x + 5, not −2x − 5. The minus multiplies every term in the bracket. This one sign slip causes more wrong answers than anything else this week.

Remember

Always check by putting your answer back into the original equation. It takes 20 seconds and catches almost every slip.

2 · Clear the fractions first

Fractions make every step harder. So get rid of them at the start: multiply both whole sides by the LCD (the smallest number every denominator divides into). Every fraction turns into a whole-number expression.

Example
Solve 2x + 14 = x − 36 + 2.
  1. Denominators 4 and 6. The LCD is 12.
  2. Multiply every term by 12: 12 · 2x + 14 = 3(2x + 1), 12 · x − 36 = 2(x − 3), and 12 · 2 = 24.
  3. So 3(2x + 1) = 2(x − 3) + 24, which is 6x + 3 = 2x + 18.
  4. 4x = 15, so x = 15/4.
  5. Check: left (7.5 + 1) ÷ 4 = 2.125, right (3.75 − 3) ÷ 6 + 2 = 2.125 ✓
Answer: x = 15/4
⚠️ Trap

Two classic slips. (1) Forgetting the lonely number: the + 2 must be multiplied by 12 too, giving 24, not 2. (2) A minus in front of a fraction: 12 · (−x + 24) is −3(x + 2) = −3x − 6. Keep the top in brackets until the minus has reached every term.

Remember

A fraction bar is a hidden bracket. When you clear it, write brackets around the top first.

3 · Word problems: one letter, one equation

The hard part of a word problem is not the algebra — it is choosing the letter. Write down exactly what it means, with units: “Let s be the number of dollars my sister has now.” Then write everything else in terms of s, and turn the last sentence of the story into an equation.

Phrases to translate carefully: “7 more than a number” is n + 7; “divided by 7 more than the number” means the whole n + 7 is the bottom; “twice as much as he has” means me = 2 × him.

Example
If Mia gives her sister $4, they will have the same amount. If instead her sister gives Mia $10, Mia will have three times as much as her sister. How much does her sister have now?
  1. Let s be the number of dollars the sister has now.
  2. Giving $4 makes them equal, so Mia has $8 more (she loses 4, her sister gains 4). Mia has s + 8.
  3. Second story: sister gives 10. Mia has s + 8 + 10 = s + 18, sister has s − 10.
  4. “Three times as much”: s + 18 = 3(s − 10), so s + 18 = 3s − 30, 48 = 2s, s = 24.
  5. Check: Mia has 32. Gives 4 → 28 and 28 ✓. Sister gives 10 → Mia 42, sister 14, and 42 = 3 × 14 ✓
Answer: $24
Example · the tank
A rain barrel is 13 full. After 4 gallons are poured in, it is 35 full. How many gallons does the barrel hold?
  1. Let C be the number of gallons the full barrel holds.
  2. Before: 13C gallons. After: 35C gallons. The difference is the 4 gallons added.
  3. 35C − 13C = 4. Multiply by 15: 9C − 5C = 60, so 4C = 60, C = 15.
  4. Check: 5 + 4 = 9, and 9 is 35 of 15 ✓
Answer: 15 gallons
⚠️ Trap

“If I give you $4 we are equal” does not mean I have $4 more. I lose 4 and you gain 4, so the gap was 8. Draw two bars if you are unsure.

4 · Consecutive integers: start in the middle

For an odd number of consecutive integers, call the middle one n. Five of them are n − 2, n − 1, n, n + 1, n + 2. The minus and plus cancel in pairs, so the sum is just 5n. Seven of them add to 7n, nine add to 9n.

You can also call the smallest one n — it still works, you just carry more numbers around. Whatever you choose, remember the question might ask for a different integer than the one you called n.

Example
Five consecutive integers add up to 257 times the largest of them. What is the smallest?
  1. Let n be the middle integer. Sum = 5n. Largest = n + 2.
  2. Equation: 5n = 257(n + 2).
  3. Multiply by 7: 35n = 25n + 50, so 10n = 50, n = 5.
  4. The integers are 3, 4, 5, 6, 7. The smallest is n − 2 = 3.
  5. Check: 3 + 4 + 5 + 6 + 7 = 25, and 257 × 7 = 25 ✓
Answer: 3
⚠️ Trap

Finding n and stopping. Here n = 5 is the middle; the question wanted the smallest. Re-read the last line before you answer.

5 · Linear in disguise — and values that are banned

Some equations look scary — an x2, an a3, a letter on the bottom — but turn into a plain linear equation once you simplify. Two ways the disguise comes off:

  1. Simplify each side first. 5x + 15x + 3 = 5(x + 3)x + 3 = 5. The x’s cancel.
  2. Treat a chunk as one letter. If b3 appears everywhere, call it u. Solve for u, then find b.

The banned values. You can never divide by zero. So before you start, write down every value that makes a denominator zero — for 5x + 15x + 3 that is x = −3. If your final answer is a banned value, it is not a solution (it is called extraneous).

Example
Solve 5x + 15x + 3 = 18x2 + 6x6x.
  1. Banned: x = −3 (left bottom) and x = 0 (right bottom).
  2. Left: 5(x + 3)x + 3 = 5. Right: 6x(3x + 1)6x = 3x + 1.
  3. Now it is linear: 5 = 3x + 1, so x = 4/3.
  4. Is 4/3 banned? No. So it is the answer.
Answer: x = 4/3
Example · treat a chunk as one letter
Find all real b with 8b3 + 2 − 3 = −b3b3 + 2.
  1. Let u = b3. Banned: u = −2. The equation is 8u + 2 − 3 = −uu + 2.
  2. Multiply both sides by u + 2: 8 − 3(u + 2) = −u.
  3. 8 − 3u − 6 = −u, so 2 = 2u, u = 1. Not banned ✓
  4. b3 = 1, so b = 1.
Answer: b = 1
⚠️ Trap

Solve xx − 3 = 3x − 3 + 2. Multiply by x − 3: x = 3 + 2(x − 3), so x = 3. Looks done — but x = 3 makes both denominators zero. It is banned, so this equation has no solution. Always check your answer against the banned list.

Remember

Never divide both sides by something that could be zero — you can lose a solution. In a3 + 1 = a + 3a, multiply by 3a instead: a2 + 3a = 3a + 9, so a2 = 9 and a = 3 or a = −3. If you had cancelled the (a + 3) you would have missed a = −3.

6 · No solution, or infinitely many

After tidying, every linear equation looks like (number)·x + (number) = (number)·x + (number). Compare the two sides:

x-numbersPlain numbersResult
differentanythingexactly one solution
samedifferentno solution — the x’s cancel and you get something false like 6 = 5
samesameinfinitely many — you get something always true like 6 = 6
Example
How many solutions does 3(x + 2) = 3x + 5 have? And 2(x + 3) = 2x + 6?
  1. First: 3x + 6 = 3x + 5. Subtract 3x: 6 = 5. False, so no solution.
  2. Second: 2x + 6 = 2x + 6. Both sides are identical, so every x works — infinitely many.
Answer: none; infinitely many
Example · fill in the blanks
Fill in the boxes so that 2(x − 5) + ▢x = 7x + ▢ has no solutions.
  1. Tidy the left: (2 + ▢)x − 10.
  2. For no solution the x-numbers must match: 2 + ▢ = 7, so the first box is 5.
  3. The plain numbers must be different: the second box can be anything except −10 (say, 0).
Answer: 5, and anything but −10
Remember

“No solution” is a real answer, not a failure. When the x’s vanish, read what is left: false means none, true means all.
