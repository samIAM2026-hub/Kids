🔢 Exponent Rules

Seven rules run every exponent problem. The skill is not remembering them — it is spotting which one to use: put everything on the same base, let negative exponents flip, and track each letter’s exponent separately.

Where you are on AoPS

You did most of Week 1 — Problems 1–4 and 10 are done. The ones that got away were the negative-exponent simplify (5), the “given 2x = 7” question (7), and the fill-in-the-blank puzzles (6, 8, 9). Every one of those has a twin on this page.

1 · The rules in one table

RuleExample
Multiply, same base → add exponentsa3 · a4 = a7
Divide, same base → subtract exponentsa9 ÷ a4 = a5
Power of a power → multiply exponents(a3)4 = a12
Power of a product → every factor gets it(2a)3 = 8a3
Zero exponenta0 = 1 (a ≠ 0)
Negative exponent → flipa−3 = 1a3
Negative power of a fraction → flip the fraction(25)−2 = (52)2 = 254
Example
Compute (−3)4 − 34 + (−2)3 − 23.
  1. (−3)4: four negatives multiplied → positive. (−3)4 = 81.
  2. 34 = 81.
  3. (−2)3: three negatives → negative. (−2)3 = −8.
  4. 23 = 8.
  5. Put it together: 81 − 81 + (−8) − 8 = −16.
Answer: −16
⚠️ Trap

−34 and (−3)4 are different. Without brackets the exponent only touches the 3: −34 = −(34) = −81. With brackets the minus is inside: (−3)4 = +81.

2 · Same base first

Most AoPS exponent problems mix numbers like 4, 8 and 16, or 9, 27 and 81. Before doing anything else, rewrite every number as a power of the same prime. Then the rules can work.

Base 2Base 3Base 5
4 = 22 · 8 = 23 · 16 = 24 · 32 = 25 · 64 = 269 = 32 · 27 = 33 · 81 = 34 · 243 = 3525 = 52 · 125 = 53 · 625 = 54
Example
Compute 23 · 42 · 825 · 16 without a calculator.
  1. Rewrite with base 2: 42 = (22)2 = 24, 8 = 23, 16 = 24.
  2. Top: 23 · 24 · 23 = 23+4+3 = 210.
  3. Bottom: 25 · 24 = 29.
  4. Divide: 210−9 = 21 = 2.
Answer: 2
Example · solving for an exponent
Solve for y if 9y = 34 · 273812.
  1. Everything is a power of 3: 273 = (33)3 = 39 and 812 = (34)2 = 38.
  2. Right side: 34+9−8 = 35.
  3. Left side: 9y = (32)y = 32y.
  4. Same base, so the exponents must match: 2y = 5, so y = 5/2.
Answer: y = 5/2
⚠️ Trap

Don’t multiply everything out. On your Week 1 writing problem you turned the whole thing into giant numbers like 387,420,489. It worked, but it took far longer — and one slip (writing 95 = 5049 instead of 59,049) nearly cost you. Same base first keeps every number tiny.

3 · Negative exponents just flip

a−n means “put an on the other floor of the fraction.” A negative exponent never makes anything negative. When a whole bracket has a negative power, give the power to every factor inside, then flip what is still negative.

Example
Simplify (a2b)3(3−1a−2)−2.
  1. Top: (a2b)3 = a6b3.
  2. Bottom: the −2 hits both factors. (3−1)−2 = 32 = 9 and (a−2)−2 = a4. So the bottom is 9a4.
  3. Divide: a6 ÷ a4 = a2.
Answer: a2b39
⚠️ Trap

Forgetting that the number gets the power too. In (3−1a−2)−2 the 3 is inside the bracket, so it becomes 32, not 3.

4 · Use what you’re given — you never need x

Questions like “given 2x = 7, find …” look impossible, because x is not a nice number. You don’t need x. Rewrite what they ask for so that 2x appears, then swap in the 7.

Example
Given 3x = 5, find 9x+1.
  1. Same base: 9x+1 = (32)x+1 = 32x+2.
  2. Split it: 32x+2 = 32x · 32 = (3x)2 · 9.
  3. Swap in 3x = 5: 52 · 9 = 225.
Answer: 225
Example
Given 2x = 5, find 8x−1.
  1. 8x−1 = (23)x−1 = 23x−3.
  2. 23x−3 = 23x23 = (2x)38.
  3. Swap in 5: 1258.
Answer: 1258
Remember

A minus in the exponent becomes a division: am−n = am ÷ an. A plus becomes a multiplication: am+n = am · an.

5 · Fill-in-the-blank puzzles: one letter at a time

AoPS loves puzzles where you put given pieces into blanks. Don’t try orders at random. Follow one letter’s exponent through the whole expression. Usually one letter forces where a piece must go, and then the rest falls into place.

Example
Put xy, x2y and xy3 into A, B and C (one each) so that A2 · BC = x3y6.
  1. Follow y. A counts twice (it is squared), B counts once, C counts minus once.
  2. Only xy3 has a big y-exponent. If it is A: 2·3 + 1 − 1 = 6 ✓. If it is B: 2·1 + 3 − 1 = 4 ✗. If it is C: 2·1 + 1 − 3 = 0 ✗. So A = xy3.
  3. Now follow x: 2·1 + (x-exponent of B) − (x-exponent of C) = 3, so B’s x-exponent is one more than C’s. That means B = x2y and C = xy.
  4. Check: (xy3)2 · x2y ÷ xy = x2+2−1y6+1−1 = x3y6 ✓
Answer: A = xy3, B = x2y, C = xy
Remember

“Constant” means no x left — the x-exponents add up to 0. It does not mean the answer is 0. For example (2x3)2 · (x−6) has x-exponent 6 − 6 = 0, and the constant is the 4 that is left over. (On Week 1 Problem 9(b) you typed 0 — this is why it was marked wrong.)
