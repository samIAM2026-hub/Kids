《纸船和风筝》拼音乐园 —— 真人录音放这里
Human voice recordings for the Zhi Chuan He Feng Zheng pinyin game.

怎么录 / How to record
  用 Chrome 打开 ../../Chinese-Pinyin-Recorder-Zhi-Chuan-He-Feng-Zheng.html
  点「选择 audio 文件夹」→ 选这个 zhichuan 文件夹 → 逐行录音，自动保存。

文件名规则 / File naming
  文件名必须等于游戏里的 id，例如：
    c-zhi.webm        纸
    c-piao-shui.webm  漂（水）
    c-piao-feng.webm  飘（风）
    w-fengzheng.webm  风筝
    s-3.webm          松鼠折了一只纸船，放在小溪里。
    p-8.webm          妈妈在厨房里炒菜，真香！
  支持的格式：.webm / .m4a / .mp3 / .wav / .ogg（Chrome 录出来是 .webm）

没有录音的词，游戏会自动用浏览器的机器音顶上 —— 可以一次只录几个，慢慢补。
