AoPS Intro to Algebra · Week 6 · Linear Equations with Multiple Variables

⚖️ Systems of Equations

Two unknowns need two equations. The whole game is to make one letter disappear — by adding the equations, or by swapping one letter for what it equals. Then the problem is a one-variable equation you already know how to solve.

Where you are on AoPS

Week 6 is a fresh start: you haven’t tried any of the 10 problems yet, and that’s fine. This page walks through every idea in the set — adding equations, substitution, the “one, none or infinitely many” question, age and digit puzzles, and the multiply-and-divide trick. Do the test here first, and the real 10 will feel familiar.

1 · Elimination: add or subtract the equations

If two things are equal, and two other things are equal, then their sums are equal too. So you can add (or subtract) two equations, left side to left side and right side to right side. Pick the move that makes one letter cancel out.

If no letter cancels yet, multiply a whole equation first so that one letter has matching (or opposite) coefficients.

Example
Solve
x + y = 21
x − y = 5
  1. The y’s have opposite signs, so add: (x + y) + (x − y) = 21 + 5, which is 2x = 26.
  2. So x = 13.
  3. Put it back into the first equation: 13 + y = 21, so y = 8.
  4. Check in the other equation: 13 − 8 = 5 ✓
Answer: (x, y) = (13, 8)
Example · multiply first
Solve
3x + 2y = 16
5x − 4y = −10
  1. Nothing cancels yet. But 2y doubled is 4y, which would cancel the −4y.
  2. Multiply the whole first equation by 2: 6x + 4y = 32.
  3. Add it to the second: 11x = 22, so x = 2.
  4. Back into the first: 6 + 2y = 16, so y = 5. Check: 10 − 20 = −10 ✓
Answer: (x, y) = (2, 5)
Remember

Sometimes you don’t need x and y at all. If 4a + 7b = 30 and 7a + 4b = 36, just add them: 11a + 11b = 66, so a + b = 6 in one step. When a question asks for a combination like a + b, try adding or subtracting the equations before you solve for each letter.

2 · Substitution — and clear fractions first

If one equation already says “x = something”, use it. Replace x in the other equation with that something. Now only one letter is left.

If an equation has fractions, multiply the whole equation by the denominator first. Whole numbers are much easier to eliminate.

Example
Solve
4x + y = 11
x = 2y − 4
  1. The second equation tells you what x is. Put (2y − 4) in place of x in the first: 4(2y − 4) + y = 11.
  2. Expand: 8y − 16 + y = 11, so 9y = 27 and y = 3.
  3. Then x = 2·3 − 4 = 2.
  4. Check in the first: 8 + 3 = 11 ✓
Answer: (x, y) = (2, 3)
Example · fractions first
Solve
x3 + 2y = 4
4y − 3x = 30
  1. Multiply the first equation by 3 (every term!): x + 6y = 12.
  2. Now x is easy to get alone: x = 12 − 6y.
  3. Substitute into the second: 4y − 3(12 − 6y) = 30, so 4y − 36 + 18y = 30, 22y = 66, y = 3.
  4. Then x = 12 − 18 = −6. Check the original: −63 + 6 = 4 ✓ and 12 + 18 = 30 ✓
Answer: (x, y) = (−6, 3)
⚠️ Trap

When you substitute, keep the brackets. 4(2y − 4) is 8y − 16, not 8y − 4. And when you clear fractions, multiply every term — including the number on the right side.

Remember

Which method is faster? If a letter is already alone (or has coefficient 1), substitute. If the coefficients line up, or nearly line up, eliminate.

3 · One, none, or infinitely many solutions

Each linear equation in x and y is a straight line. A solution is a point on both lines. So there are only three possibilities:

LinesSolutionsHow it looks
Cross onceExactly onex + y = 4 and x − y = 2
ParallelNonex + 2y = 3 and 2x + 4y = 7 — left side doubled, right side not
Same lineInfinitely manyx + 2y = 3 and 2x + 4y = 6 — everything doubled

So “no unique solution” means the left sides are multiples of each other. Then the right sides decide: same multiple → infinitely many; different → none.

Example
For which numbers k and m does this system have infinitely many solutions (p, q)?
2p − q = 6
7p + 2q = k + p − mq
  1. First tidy the second equation: move every p and q to the left. 7p − p + 2q + mq = k, so 6p + (2 + m)q = k.
  2. Infinitely many solutions means this must be the first equation times some number. The p’s go from 2 to 6, so the number is 3.
  3. Three times the first equation is 6p − 3q = 18.
  4. Match the pieces: 2 + m = −3, so m = −5; and k = 18.
Answer: k = 18, m = −5
⚠️ Trap

Don’t compare the coefficients before you tidy up. In the example, the second equation has p on both sides. If you read the p-coefficient as 7 instead of 7 − 1 = 6, every answer after that is wrong.

Remember

Fill-in-the-blank version: to make a system have no unique solution, choose the blank so the left side is an exact multiple of the other equation’s left side. For 2x + 5y = 1 and 6x + ▢y = 9, the x’s were tripled, so the box must be 15.

4 · Word problems: two letters, two sentences

Most word problems in this unit give you two facts. Name two unknowns clearly (write down what each letter means, with units). Turn each fact into one equation. Then solve the system.

For ages, the key is that time passes for everyone. “5 years ago” means subtract 5 from both ages; “in 4 years” means add 4 to both.

Example · the famous trap
A smoothie and a muffin cost $4.50 together. The smoothie costs $3 more than the muffin. How much does the muffin cost, in cents?
  1. Let the muffin cost m cents. The smoothie is $3 more, so it costs m + 300 cents.
  2. Together: m + (m + 300) = 450, so 2m = 150 and m = 75.
  3. Check: smoothie 375, muffin 75. Total 450 ✓. Difference 300 ✓
Answer: 75 cents
Example · ages
Five years ago, Uncle Ray was 6 times as old as Ben. In 4 years, Uncle Ray will be 3 times as old as Ben. How old is Uncle Ray now?
  1. Let Ray be R and Ben be B years old now.
  2. Five years ago both were 5 younger: R − 5 = 6(B − 5), so R = 6B − 25.
  3. In 4 years both are 4 older: R + 4 = 3(B + 4), so R = 3B + 8.
  4. Both equal R: 6B − 25 = 3B + 8, so 3B = 33, B = 11, and R = 41.
  5. Check: five years ago 36 and 6 (36 = 6 × 6 ✓). In four years 45 and 15 (45 = 3 × 15 ✓).
Answer: 41 years old
⚠️ Trap

In the smoothie problem, the quick guess is 150 cents (450 − 300). But then the smoothie is 300 and the difference is only 150, not 300. Always check your answer against both facts in the story.

5 · Digit problems: 10t + u

A two-digit number with tens digit t and units digit u is worth 10t + u, not t + u and not tu. Reversing the digits gives 10u + t.

Subtract them and something neat happens: (10t + u) − (10u + t) = 9t − 9u = 9(t − u). So the difference between a number and its reverse is always 9 times the difference of the digits.

Example
A two-digit number has digits that add to 11. When you reverse its digits, the new number is 27 more than the original. What is the original number?
  1. Let the number be 10t + u. Digit sum: t + u = 11.
  2. Reversed is bigger by 27: (10u + t) − (10t + u) = 27, so 9(u − t) = 27 and u − t = 3.
  3. Add the two equations: 2u = 14, so u = 7 and t = 4.
  4. The number is 47. Check: 74 − 47 = 27 ✓ and 4 + 7 = 11 ✓
Answer: 47
Remember

After you set up 10t + u, the digit problem turns into a tiny system — and very often you finish it by adding the equations.

6 · Multiply and divide whole equations

When the equations are products like pq2 = 18, adding does not help. Instead multiply or divide the equations. Choose the move that makes the exponents of one letter cancel, using the exponent rules from Week 1.

If you have ab4 and a2b3, squaring the first gives a2b8. Divide by a2b3 and the a’s vanish, leaving b5.

Example
Find real numbers p and q with
pq2 = 18
p2q = 12
  1. Multiply the equations: p3q3 = 216, so (pq)3 = 216 and pq = 6.
  2. Divide the first by the second: pq2p2q = qp = 1812 = 32, so q = 1.5p.
  3. Put that into pq = 6: 1.5p2 = 6, so p2 = 4.
  4. p = 2 gives q = 3. (p = −2 gives q = −3, but then pq2 = −18 ✗.) Check: 2 · 9 = 18 ✓ and 4 · 3 = 12 ✓
Answer: (p, q) = (2, 3)
Example · add, subtract, and watch for zero
Find every possible value of m if
m + mn2 = 52n
m − mn2 = −20n
  1. Add: 2m = 32n, so m = 16n.
  2. Subtract: 2mn2 = 72n, so mn2 = 36n.
  3. Substitute m = 16n: 16n3 = 36n. Move everything to one side: 4n(4n2 − 9) = 0.
  4. So n = 0, or n2 = 9/4 which means n = ±3/2.
  5. Then m = 16n gives m = 0, 24, or −24. All three check in both equations.
Answer: m = 24, −24, or 0
⚠️ Trap

Never divide both sides by a letter that could be 0. If you divide 16n3 = 36n by n, you lose the solution n = 0, m = 0. Move everything to one side and factor instead.
